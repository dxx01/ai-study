# Cursor 项目规则（ai-study）

| 文件 | 生效方式 |
|------|----------|
| `agent-communication.mdc` | **Always Apply**：全仓库 Agent 对话通用约定 |
| `java-enterprise-coding-standards.mdc` | 打开/编辑 `*.java`、`*.kt`、`pom.xml` 时自动附加 |
| `frontend-standards.mdc` | 打开/编辑前端相关扩展名时自动附加 |

Java 规范已从 `%USERPROFILE%\.cursor\rules` 迁移至此，便于 D 盘工作区加载与 git 共享。

**请在 Cursor Settings → Rules → User Rules 中删除原先粘贴的「Java 企业级编码规范」长文**，避免与项目规则重复占用上下文。
